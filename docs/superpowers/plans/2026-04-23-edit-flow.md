# Edit Flow Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Reuse `CreateRecordScene` for editing — open it preloaded with an existing `Record`, persist changes via `RecordStore.update`, delete orphaned photos.

**Architecture:** Add an `editing:` init to `CreateRecordModel`, parameterize `PersonTopNav` title and `SaveButton` label, change `CreateRecordScene.onSave` to emit a `CreateRecordOutcome` enum (`.create(RecordDraft)` / `.update(Record)`), surface an `onEditRecord` callback from `RecordsListScene` so AppFeature can flip `router.editingRecord`, and add a `.sheet(item: $router.editingRecord)` in `RootScene` that loads the photo, dispatches the outcome, and cleans up orphan photo files when the photo bytes change.

**Tech Stack:** Swift 6 (strict concurrency), SwiftUI, Swift Testing, `@Observable`, SwiftData (via `RecordStore`), file-system `PhotoStore`, iOS 17+.

**Design choices (locked):**
- Top nav title in edit mode: `EDIT`
- Save button label in edit mode: `UPDATE`
- Photo: when the user replaces the photo, delete the previous `PhotoID` from `PhotoStore`
- Ambient (`createdAt`, `metadata`, `location`, `guillocheShape`): pinned to the original record — never re-roll on edit

```swift
#if os(iOS)
@MainActor
private struct EditingSheetContent: View {
    let record: Record
    let environment: AppEnvironment
    @Bindable var photoCache: PhotoCache
    let attitude: DeviceAttitude
    let onFinish: () -> Void

    @State private var photoData: Data?
    @State private var didLoad = false

    var body: some View {
        Group {
            if didLoad {
                CreateRecordScene(
                    editing: record,
                    attitude: attitude,
                    paths: environment.cardPathProvider,
                    faceDetectionService: environment.faceDetectionService,
                    photoData: photoData,
                    photoFocus: record.photoFocus,
                    onCancel: onFinish,
                    onSave: { outcome in
                        guard case let .update(updated, newPhotoData, newPhotoFocus) = outcome else {
                            onFinish()
                            return
                        }
                        Task {
                            var resolved = updated
                            if newPhotoData != photoData {
                                if let bytes = newPhotoData {
                                    resolved.photoID = try? await environment.photoStore.save(bytes)
                                    resolved.photoFocus = newPhotoFocus
                                } else {
                                    resolved.photoID = nil
                                    resolved.photoFocus = nil
                                }
                                if let oldID = record.photoID, oldID != resolved.photoID {
                                    try? await environment.photoStore.delete(oldID)
                                    photoCache.invalidate(oldID)
                                }
                            }
                            try? await environment.recordStore.update(resolved)
                            // Invalidate the cache for this slot so the list reloads
                            // the new bytes.
                            photoCache.invalidate(resolved.photoID)
                            await photoCache.preload([resolved], using: environment.photoStore)
                            onFinish()
                        }
                    }
                )
            } else {
                Color.clear
            }
        }
        .task {
            if let id = record.photoID {
                photoData = try? await environment.photoStore.load(id)
            }
            didLoad = true
        }
    }
}
#endif
```

Notes:
- The `Group { if didLoad { ... } else { Color.clear } }` keeps `CreateRecordScene` from being constructed until photo bytes are loaded, so the model's `photoState` starts in `.ready` (not `.none` followed by a refresh).
- `photoData != newPhotoData` compares full `Data` byte-equality. Photos in this app are small (camera/photos picker output), so byte-compare is fine. If perf becomes a concern, switch to comparing CryptoKit hashes; not needed now.
- We never re-save the photo when it didn't change — `newPhotoData != photoData` short-circuits.
